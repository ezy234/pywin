The continuous portal bot runs in 45-minute processing sessions, saving to portal_candidates in theProject. Run it manually from GitHub Actions. It uses GROQ_MODEL from Actions secrets, defaulting to openai/gpt-oss-120b. Saved records are skipped on resume; no new run is queued when processing finishes. Failed portal lookups retain the original skip behavior. Cancel the active run to stop the chain. The PDF source uses the original Supabase secrets; the destination uses CONTINUOUS_SUPABASE_URL and CONTINUOUS_SUPABASE_KEY. Validate locally with: python -m unittest discover -s tests -v.
